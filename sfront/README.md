## 🚀 Quick Start

### Prerequisites
- Node.js 16+
- Backend: http://localhost:5000

### Setup
```bash
npm install
npm run dev
```
Opens at http://localhost:3000

✅ User authentication (register/login/logout)

## 🛠️ Tech Stack

- React 18.2
- Zustand 4.4 (state)
- Vite 5.4
- Tailwind CSS 3.4
- Framer Motion (animations)
- Lucide React (icons)
